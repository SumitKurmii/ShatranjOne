# Chess Engine Lab

## Goal
Build a chess application with my own C++ chess engine, a React frontend, and a Node.js backend.

## Engine
- Generate legal chess moves.
- Search to a target depth of 12 using alpha-beta pruning.
- Use move ordering to prioritize promising moves, including captures.
- Use a transposition table to remember previously analyzed positions.
- Measure engine performance and test correctness.

## Application
- Play against the engine.
- Analyze positions and display recommended moves.
- Save games and review previous games.
- Eventually search historical games and investigate neural-network evaluation.

## Learning goals
- Improve C++ and algorithmic problem-solving.
- Learn backend development and database design.
- Practice system design, testing, deployment, and CI.

## Initial rule
Build incrementally. Correctness and tests come before optimization.
